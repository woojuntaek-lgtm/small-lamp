# 작은 등불 하나

「잠들기 전 3분, 고전의 등불」 1화 「앞을 보지 못하는 사람의 등불」의 부록 앱입니다. 바빌로니아 탈무드 메길라 24b에 전하는 랍비 요세의 이야기를 바탕으로, 캄캄한 밤길을 횃불 없이 또 횃불을 들고 걸어 보는 그림, 이야기 따라 읽기, 흔히 아는 이야기(남이 부딪히지 않도록)와 원전(사람들이 나를 보고 건져 주도록)의 차이, 원전 퀴즈, 오늘 밤 내가 켜 둘 작은 등불 고르기, 3분 동안 조용히 타는 등불을 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 밤길: 오늘의 질문, 캄캄한 밤길 걸어 보기, 이야기 따라 읽기
- ② 두 가지 읽기: 흔히 아는 이야기와 원전 비교, 원전 퀴즈, 원전 한눈에
- ③ 오늘 밤 등불: 작은 등불 고르기·적기, 3분 등불

## 원전과 알림
- 원전: 바빌로니아 탈무드 메길라 24b(랍비 요세), 랍비가 마음에 걸려 한 구절은 신명기 28장 29절입니다. 우리말 문장은 영상 대본을 따랐으며 오디오북의 문장이나 음원은 쓰지 않았습니다.
- 그림과 움직임은 이야기를 옮겨 앱이 직접 그린 것입니다. 소리는 없습니다.
- 고르거나 적은 말은 저장하거나 보내지 않습니다.
